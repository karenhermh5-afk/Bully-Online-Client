Thank you for downloading Bully Online!
Let's begin by running you through the basics.


Getting started:
1. Make sure you have the Bully v1.200 patch. The Steam version already has this by default.

2. Download and install dinput8.dll to your game's directory.
https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/Win32-latest/dinput8-Win32.zip

3. Download and install the latest version of derpy's script loader to your game's directory.
https://swegta.com/dl/derpy_script_loader.asi

4. Create an account on swegta.com/online. This account is what you will use to sign into the server.

5. Use either Bully Online Launcher, Bully Online Direct Connect, or Bully Online Backup Connect to boot up your game and log into the server.


Important Notes:
1. You must have a legal copy of Bully: Scholarship Edition. Anyone found to be using a pirated version will be banned.

2. We strongly suggest you use SilentPatchBully to improve the game's performance and reduce crashes.
https://github.com/CookiePLMonster/SilentPatchBully
